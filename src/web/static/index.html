股票分析 Workflow

股票分析采用多 agent 辩论机制，通过正反方辩论深度分析股票投资价值。 辩论最多进行 10 轮，确保分析充分深入。

参与 Agent 详细说明

FundamentalsAnalyzer
基本面分析师
  • 分析财务指标（ROE、净利润率、负债率）
  • 评估行业地位和竞争优势
  • 判断估值水平（PE、PB）
  • 给出基本面评分（1-10分）
TechnicalAnalyzer
技术面分析师
  • 分析K线形态和趋势
  • 计算技术指标（MACD、KDJ）
  • 判断支撑位和压力位
  • 给出买入/卖出信号
BullAdvocate
正方辩论师
  • 提出支持买入的理由
  • 强调基本面和技术面优势
  • 反驳反方的风险担忧
  • 提供积极的市场预期
BearAdvocate
反方辩论师
  • 提出支持卖出/观望的理由
  • 指出基本面和技术面风险
  • 反驳正方的乐观预期
  • 提供谨慎的风险提示
Judge
投资决策师
  • 客观评估正反方论点
  • 权衡买入和卖出理由
  • 考虑基本面和技术面评分
  • 做出最终决策（buy/sell/hold）
PositionAdvisor
持仓顾问
  • 根据决策给出操作建议
  • 建议仓位和买入金额
  • 设置止损止盈价位
  • 提供风险提示

输入与输出

输入参数
  • 股票代码：如 000001.SZ
  • 当前持仓：持有该股票的金额（元）
输出结果
  • 决策：buy/sell/hold
  • 操作建议：买入金额/卖出数量
  • 止损止盈：价位建议
  • 风险提示：需关注的风险点

市场分析 Workflow

市场分析采用线性流程，依次分析宏观形势、热点板块、行业潜力和个股机会。 流程简洁高效，全面把握市场动态。

市场宏观分析
判断牛市/熊市/震荡市，分析大盘走势
Agent: MarketMacroAnalyzer
↓
板块分析
识别热点板块，分析资金流向
Agent: SectorAnalyzer
↓
行业分析
评估行业增长潜力、政策支持
Agent: IndustryAnalyzer
↓
个股筛选
从热点行业中筛选潜力个股
Agent: StockScreener

参与 Agent 详细说明

MarketMacroAnalyzer
市场宏观分析师
  • 分析主要指数走势（上证、深证、创业板）
  • 判断市场成交量变化
  • 评估涨跌比例和市场情绪
  • 给出市场形势判断（牛市/熊市/震荡）
SectorAnalyzer
板块分析师
  • 分析板块涨幅排名
  • 识别资金流向热点
  • 判断板块热度持续性
  • 给出热点板块 Top 5
IndustryAnalyzer
行业分析师
  • 分析行业增长趋势
  • 评估政策支持情况
  • 判断市场规模和竞争格局
  • 给出行业评分和投资建议
StockScreener
个股筛选师
  • 从热点行业筛选个股
  • 评估行业龙头地位
  • 分析财务和技术指标
  • 给出推荐个股 Top 10

输入与输出

输入参数
  • 无需输入：自动获取市场数据
  • 数据源：Akshare（实时A股数据）
输出结果
  • 市场形势：牛市/熊市/震荡市
  • 热点板块：Top 5 板块及分析
  • 行业分析：行业潜力评分
  • 推荐个股：Top 10 个股及理由
